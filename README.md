# Business Entity Resolution: ML Challenge 2026

This is a solution for matching business records from Sources 2 and 3 to the
deduplicated Source 1 reference records. It uses multi-key blocking and a
two-stage LightGBM matcher.

* Validation macro F0.5: **0.981** on a held-out 20 % of training entities
* Blocking: **96.7 % recall at ~5 candidates per Source 1 entity** (6.17 on test)

| path | contents |
|---|---|
| `code/business_entity_resolution/` | runnable pipeline (`src/`), run instructions (`README.md`), pinned dependencies |
| `Documentation_template.md` | methodology write-up: EDA, blocking, features, model, results, error analysis |
| `output/` | `matching_results.tsv` and `candidate_pairs.tsv` (generated by the pipeline and not committed because of file size) |
