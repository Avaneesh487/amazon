# Business Entity Resolution: ML Challenge 2026

This is a solution for matching business records from Sources 2 and 3 to the
deduplicated Source 1 reference records. It uses multi-key blocking and a
two-stage LightGBM matcher.

* Validation macro F0.5: **0.981** on a held-out 20 % of training entities
* Blocking: **96.7 % recall at ~5 candidates per Source 1 entity** (6.17 on test)

| path | contents |
|---|---|
| `code/business_entity_resolution/` | runnable pipeline (`src/`), run instructions (`README.md`), pinned dependencies |

## Dataset

The original `dataset.zip` (1.09 GB) is stored in `dataset_parts/` as 11 pieces of
95 MB each, because GitHub rejects files larger than 100 MB. To rebuild and extract it:

```bash
cat dataset_parts/dataset.zip.part* > dataset.zip
unzip dataset.zip
```

On Windows PowerShell, use `cmd /c copy /b dataset_parts\dataset.zip.part* dataset.zip`.

Expected SHA-256 of `dataset.zip`:
`c008970bd30635c3d7b2e2f3b1674a1ac889c8c326f7b0ce50eab77aa586850a`.
Extracting gives `dataset/train/` (source 1–3 files and ground truth) and
`dataset/test/` (source 1–3 files).

To reproduce the results, see
[`code/business_entity_resolution/README.md`](code/business_entity_resolution/README.md).
